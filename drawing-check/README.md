# 図面数値チェッカー

完成図を正として、意匠図・構造図・各業者の施工図（PDF）の数値を照合し、数値の上にマーカーを引くブラウザアプリです。

## 使い方
1. `index.html` をブラウザ（Chrome / Edge 推奨）で開く
2. 「完成図（基準）」にPDFを1枚、「照合する図面」に比較したいPDFを複数選択
3. 図面ごとの一致色、不一致の共通色を指定して「照合を開始」
4. 結果表・図面ビューア・図面コメントを確認し、注釈PDF／レポート（.txt）／一覧（.csv）を保存

## 重ね合わせ（レイヤー）
- 完成図（灰色）の上に、各図面を図面ごとの色の線で重ねて表示します。線のずれが図面の違いです。
- レイヤーごとに表示／非表示、不透明度、マーカーの表示、重なり順（▲▼）を変えられます。
- 位置合わせは通り芯記号や寸法の位置から自動で行います（縮尺・位置・回転の違いに対応）。
- 重ねる相手の判断：図の種類（平面図・平面詳細図・天井伏図・見上げ図・伏図／立面図／断面図／展開図など）と階を、ファイル名と図面名から判定します。
  - 平面系どうしは重ねます。見上げ図は左右反転して重ねます。
  - 断面図と平面図など種類が違う図面、階が違う図面は重ねず、理由を表示します。

## 判定
- 一致：完成図に同じ数値がある → 図面ごとの指定色
- 不一致：完成図に同じ数値がない → 全図面共通の指定色（近い数値・差・数字の入れ替わりをコメント）
- 要確認：OCRの信頼度が低く、不一致だった数値 → 要確認色
- 該当なし：完成図の同じ位置に数値がない（部材寸法など完成図に記載のない情報）→ 該当なし色
- 重ねられる図面は「完成図の同じ位置にある数値」と比較します（同じ値が図面中に何度も出ても取り違えません）。
- 寸法の合計チェック：各図面の中で、寸法の合計が全体寸法と合わない箇所を指摘します（完成図自体の誤りも検出）。
- 複数の図面が完成図と同じ別の値を書いている場合は「完成図側の誤記の可能性」とコメントします。

## 精度のための処理
- CAD出力で1文字ずつ分割された文字や重ね書きを結合・除去
- 回転文字（縦の寸法）に対応
- 日付・縮尺（1:100、1/50）・図面番号（A-101）を自動除外
- 周辺の通り芯・室名・隣接寸法を照合して、完成図の対応箇所を特定
- 画像PDFや文字化けしたPDFはOCR（Tesseract.js、約300dpi、0°/90°の2方向読取）
- OCRの数値は切り出して3倍に拡大し、数字専用設定で読み直し、2回の結果が食い違えば「要確認」にします

## 注意
- 完成図に記載のない情報（部材寸法など）は「不一致」として表示されます。コメントで区別しています。
- OCRとライブラリはCDNから読み込むため、インターネット接続が必要です。
