# 図面数値チェッカー

完成図を正として、意匠図・構造図・各業者の施工図（PDF）の数値を照合し、数値の上にマーカーを引くブラウザアプリです。

## 使い方
1. `index.html` をブラウザ（Chrome / Edge 推奨）で開く
2. 「完成図（基準）」にPDFを1枚、「照合する図面」に比較したいPDFを複数選択
3. 図面ごとの一致色、不一致の共通色を指定して「照合を開始」
4. 結果表・図面ビューア・図面コメントを確認し、注釈PDF／レポート（.txt）／一覧（.csv）を保存

## 判定
- 一致：完成図に同じ数値がある → 図面ごとの指定色
- 不一致：完成図に同じ数値がない → 全図面共通の指定色（近い数値・差・数字の入れ替わりをコメント）
- 要確認：OCRの信頼度が低く、不一致だった数値 → 要確認色

## 精度のための処理
- CAD出力で1文字ずつ分割された文字や重ね書きを結合・除去
- 回転文字（縦の寸法）に対応
- 日付・縮尺（1:100、1/50）・図面番号（A-101）を自動除外
- 周辺の通り芯・室名・隣接寸法を照合して、完成図の対応箇所を特定
- 画像PDFはOCR（Tesseract.js、約300dpi、0°/90°の2方向読取）

## 注意
- 完成図に記載のない情報（部材寸法など）は「不一致」として表示されます。コメントで区別しています。
- OCRとライブラリはCDNから読み込むため、インターネット接続が必要です。
