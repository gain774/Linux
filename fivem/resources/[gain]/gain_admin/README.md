# gain_admin

管理メニュー（F6）とコマンド。

## 参考にしたもの

**該当する既存実装の設計だけを参照した。** 管理ツールは各フレームワークが同梱しており
（qb-adminmenu、esx_adminplus など）、機能の並びはほぼ共通している。コードは見ていない。

## 変えたところ

- **自分と同格以上の相手には強制系を実行できない。** 権限を持つ者同士の事故と乱用を防ぐ
- **コンソール（`src == 0`）は権限判定を迂回する。** RCON / txAdmin から使えないと復旧手段が無くなる
- 所持金の付与は `kind = 'admin'` を伴うので、台帳に誰がいつ付与したかが残る

## コマンド

`/gwhoami` `/gkick` `/gban` `/gunban` `/ggivemoney` `/gsetperm`
