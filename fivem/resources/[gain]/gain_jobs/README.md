# gain_jobs

就職・出退勤・巡回業務・給料。

## 立ち位置

**この実装は職業3種（清掃員・タクシー・運送業）を決め打ちしている。**
サーバーの軸を「仕組みだけ提供し、中身は決めない」と定めた以上、この形は軸に合わない。
プレイヤーが職業を自分で定義できる仕組みは別途 CIVIC として設計しており、
こちらはそれまでの暫定実装として残している。

## 参考にしたもの

ESX / QBCore のジョブ設計を読み、グレードと給料の持ち方だけ学んだ。コードは使っていない。

## 変えたところ

- **到達判定と報酬額はサーバー側で再計算する。** クライアントから金額を受け取らない
- **報酬を付与してからミッションを消す。** 順序を逆にすると、付与に失敗したときに
  再受け取りができなくなる
- 給料と業務報酬は `kind` を伴うので、台帳に区別が残る
