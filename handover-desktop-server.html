ノートPC（Latitude 5320）で稼働中の FiveM ＋ Claude Code サーバーを、余っている Ryzen 9 7900X で デスクトップに移行する検討。中古中心・低予算が前提。本セッションでは調査と方針検討のみを行い、 ファイル変更・コミットは一切していない。

目的

何をしようとしていたか。

  • 現行の Latitude 5320（i7-1185G7 / 4C8T）は性能不足。手持ちで余っている Ryzen 9 7900X を使ってデスクトップサーバーを組み、そちらへ移行したい。
  • 用途は README 記載の通り FiveM ゲームサーバーの常時稼働 ＋ 外出先から SSH で使える Claude Code 環境の同居。
  • 予算は「中古で安く済ませたい」。具体的な上限額は 不明。
  • 本セッションで扱ったのは、構成候補・概算価格・CPU 選定・同時接続人数の見積もり。

決定事項・技術的結論

セッション内で根拠を示して結論づけた項目。ただし 要承認 が付いたものは ユーザーがまだ採否を明言していないため、確定ではなく推奨に留まる。

グラフィックボードは不要確定

7900X は iGPU（RDNA2 2CU）内蔵で BIOS 画面が出る。7800X3D も Radeon Graphics 内蔵。headless 運用のため描画自体が発生しない。GPU が要るのはローカル LLM／画像生成／配信ホスト／大量トランスコードの場合のみ。Claude Code は API 経由なのでローカル CPU・GPU をほぼ使わない。

メモリは 32GB で十分。64GB は買わない確定

FiveM は「足りていれば速度は変わらない」性質。64人規模の RP でも実使用 12〜20GB。32GB → 64GB にしても FiveM は速くならない。現在の DDR5 相場では 64GB 化は純粋な浪費。増設余地のためマザボは DIMM 4本のものが望ましい。

SSD は 500GB で容量的に問題なし確定

Ubuntu Server 約10GB ＋ FiveM 20〜40GB（README 実測値）＋ Node/Docker 10〜20GB＝合計 40〜70GB。500GB で 7〜10倍の余裕。ただし円/GB では 1TB の方が有利（+7,000円程度で倍容量）。容量より TLC・DRAM 搭載品を選ぶことが重要（24時間ログ書き込みのため）。

電源は新品を使う確定

24時間稼働で経年電源が故障するとマザボ・SSD を巻き添えにする。中古完成品を買う場合も電源だけは新品に交換する前提で +7,000〜10,000円を見込む。

UPS が新たに必要になる確定

README にある通り、ノートは「バッテリーが簡易UPS代わり」だった。デスクトップ化でそれが失われる。CyberPower CP550 クラスで 8,000〜12,000円。

モニターの買い増しは不要確定

画面が必要なのは README の Phase 3（BIOS）と Phase 4（Ubuntu インストール）の2回のみ。以降は SSH。HDMI ケーブル差し替え（0円）か HDMI切替器（約2,000円）で足りる。さらにデスクトップ移行でノート（Latitude 5320）が空くため、これが SSH 操作端末になる。これは README の未確認論点「サーバーを操作する端末が未定」の解決策でもある。

BIOS: AC Power Loss → Power On を設定確定

停電復帰で自動起動させる。Latitude での「AC Recovery = Power On」と同じ意図（README Phase 3 相当）。

CPU は 7800X3D を残す方が用途に合う要承認

「7800X3D 搭載の中古機を買い、7900X と入れ替えて片方を売る」という前提での結論。FiveM はシングルスレッド律速でキャッシュが効くため 96MB L3・1CCD の 7800X3D が 10〜25% 有利。7900X の 12コアは Claude Code が API 経由で CPU を使わないためほぼ遊ぶ。24時間の消費電力・発熱・静音も 7800X3D 有利。売却額の差は 1万円前後で決め手にならない。ただし将来ビルド／大量コンテナ／エンコードを回すなら 7900X が逆転する。

購入ルートは「中古 AM5 機を買って載せ替え」が最有力要承認

中古完成品は内部のメモリ・SSD が高騰前価格で仕入れられているため、パーツ個別購入より有利。特に 7800X3D 搭載中古機なら AM5＋DDR5 構成が確実で、最大の障壁である DDR5 代（約6万円）が本体価格に込みになる。

7900X を使う場合の設定2点7900X採用時のみ

① BIOS で ECO モード 105W（FiveM は全コア負荷を掛けないため人数・体感は落ちない。発熱・電気代・電源要件が下がる）。② 2CCD 構成のため CCD 間レイテンシを避けて FiveM を片側に固定する。fivem.service に CPUAffinity=0-11 を追加。7800X3D は 1CCD なのでこの設定自体が不要。

調査で確定した価格（2026年8〜9月 日本相場）

Web 検索で確認した実勢値。出典は末尾。

重要な訂正：セッション初期に提示した見積もり（DDR5 32GB を 7,000〜9,000円、64GB を 18,000〜23,000円 等）は大幅に誤っていた。ユーザーの指摘を受けて調査し、下表に訂正済み。初期の数値は使用しないこと。

背景：DDR5 は 2025年7月比で平均 4.4倍（2026年1月時点）に高騰。原因は AI データセンター需要・HBM への生産シフト・NAND 減産・円安。2027年後半までは高止まりの見通しで、2026年内の下落は期待できない。

性能見積もり（同時接続人数）

7900X 前提で算出。7800X3D は FiveM のサーバースレッドで 10〜25% 上回る想定のため、下表以上になる。

サーバーの中身7900X現行ノート（i7-1185G7）

一般的な RP（ESX / QBCore＋150前後のリソース）64人快適・100人まで実用8〜16人

友人内カジュアル回線側で決まる16人

README の「目安16人」はノート側の制約による数値であり、デスクトップ移行後は適用されない。README を更新する際はこの記述の差し替えが必要。

人数を制限する要因（詰まる順）

  • ① スクリプトの質 — 出来の悪いリソース1つで Server Thread が跳ねる。CPU を強化しても解決しない。指標は txAdmin の Server Thread 5〜6ms 以下。
  • ② 回線の上り帯域 — 32人で 5〜10Mbps、64人で 15〜25Mbps を常時消費。現在の回線の上り速度は不明。
  • ③ RAM — 64人の重量級 RP で 12〜20GB。32GB で足りる。
  • ④ CPU — 上記をクリアして初めて効いてくる。
  • 設定要件 — 32人超で OneSync（Infinity）が必須。Cfx.re の無料ライセンスキー（README Phase 9 で取得するもの）で利用可。

未完了の残タスク

優先度：P1 先行必須（後続がブロックされる）／ P2 購入前に必要／ P3 記録・整備。

  1. メインPC のメモリ規格が DDR5 か DDR4 かを確認するP1

    DDR4 なら AM5 に物理的に挿さらないため「メインPCを64GB化して32GBを流用する」案（Bプラン）が丸ごと成立しない。Windows なら タスクマネージャー → パフォーマンス → メモリ の右上に規格が表示される。

    依存：なし／これがタスク2の前提

  2. どちらの CPU を残すか決定する（7900X or 7800X3D）P1

    セッションの推奨は 7800X3D を残す。ただし「サーバーを FiveM 以外の重い並列処理にも使うか」というユーザーの意向次第で逆転する。この判断が構成全体（マザボ選定・冷却・電源容量・ECO設定の要否）を左右する。

    依存：ユーザーの利用計画の申告待ち

  3. 購入ルートを確定するP1

    候補は4つ。A：パーツ個別に組む（94,000〜116,000円）／B：メインPC 64GB化＋32GB流用（サーバー側 36,000〜55,000円、総額は増）／C：中古 AM5 機を買って 7900X に載せ替え、外した CPU を売却／D：7800X3D 搭載中古機を買い、7900X を売却。推奨は C または D。

    依存：タスク1（メモリ規格）とタスク2（CPU選定）の両方

  4. 回線の上り速度を実測するP2

    同時接続人数の実質的な上限を決める要素。32人で 5〜10Mbps、64人で 15〜25Mbps が必要。光回線なら通常問題ないが未測定。

    依存：なし（CPU 選定と並行して実施可能）

  5. CGNAT かどうかを確認するP2

    README Phase 10 の論点。グローバルIPが無いとポート 30120 の開放ができず、友人への公開ができない。代替は playit.gg 等のトンネル、または友人も WARP/Tailscale に参加する方式。ハード構成とは独立だが、公開可否に直結する。

    依存：なし

  6. 中古機を買う場合の現物確認3点P2

    依存：タスク3（購入ルート確定）

移行先の前提

  • 使用予定 CPU：Ryzen 9 7900X（手持ち・取得費用 0円）。12C/24T、最大 5.6GHz、L3 64MB（32MB×2 CCD）、TDP 170W / PPT 230W、iGPU あり。
  • 比較対象：Ryzen 7 7800X3D。8C/16T、最大 5.0GHz、L3 96MB（1CCD）、TDP 120W / PPT 162W、iGPU あり。
  • プラットフォームは AM5 / DDR5 必須（DDR4 は不可）。
  • SSD の方針変更：README では「2TB を新しい PC に転用」としていたが、その 2TB は別用途に回し、サーバーには別途 500GB を用意する方針にユーザーが変更。
  • 電気代前提：31円/kWh。7900X はアイドル込み平均 70〜90W で月 1,600〜2,000円の増加見込み（ノートは約15W）。7800X3D なら 1CCD 分アイドルが低く、平均で 15〜25W（月 130〜190円）安い。
