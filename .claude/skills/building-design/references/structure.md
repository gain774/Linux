# 構造

**間取りは構造で成立している。** 柱をどこに立てるか、梁がどこまで飛ぶかで、取れる空間は決まる。
「壁を線で引いて部屋名を付ける」のは図面ではない。構造を決めずに引いた間取りは建たない。

## 構造形式の選択

| 形式 | 支える要素 | 標準スパン | 向く用途 | 制約 |
|---|---|---|---|---|
| **木造軸組（在来）** | 柱・梁 | 柱 1,820（最大 2,730） | 戸建、小規模店舗 | 開口の自由度は高いが、耐力壁のバランスが要る |
| **木造枠組壁（2×4）** | 壁（面） | 壁線 3,640 以内 | 戸建 | **壁で支えるので大きな開口が取りにくい**。間仕切り変更も不自由 |
| **RC ラーメン** | 柱・梁 | 6,000〜8,000 | 中高層、事務所、店舗 | 柱が太く（600角程度）、室内に出る |
| **RC 壁式** | 壁 | 壁の囲み 5,000 程度 | 5階以下の集合住宅 | 耐力壁を抜けない。間取りの自由度が低い |
| **鉄骨（S造）** | 柱・梁 | 6,000〜12,000（大スパン可） | 倉庫、工場、店舗 | 耐火被覆が要る。ブレースが室内に出ることがある |

**選び方**: 大きな無柱空間が要るなら S 造か RC ラーメン。小住宅なら木造軸組。
量産する集合住宅なら RC 壁式。倉庫なら S 造。用途と欲しいスパンから逆算する。

## 木造軸組の部材

下から順に、力が流れる順序でもある。

| 部材 | 役割 | 断面の目安 |
|---|---|---|
| **基礎** | 建物の荷重を地盤に流す | 布基礎 or ベタ基礎。立上り幅 120〜150、高さ GL+400 |
| **アンカーボルト** | 土台を基礎に緊結 | M12、間隔 2,700 以下、柱際は必須 |
| **土台** | 柱を受け、基礎に伝える | 105角 or 120角（ヒノキ・防腐処理） |
| **柱（管柱）** | 各階の荷重を受ける | 105角 or 120角。**間隔 1,820 が標準** |
| **柱（通し柱）** | 2階まで通す。隅角部に | 120角以上 |
| **胴差** | 2階床を受け、通し柱をつなぐ | せい 240〜300 |
| **梁・桁** | 床・屋根の荷重を柱に流す | **せい = スパン ÷ 10〜12**（松・集成材） |
| **筋交い** | 水平力（地震・風）に抵抗 | 45×90 以上。**バランスよく配置** |
| **火打** | 床・小屋の水平剛性 | 90角 |
| **大引・根太** | 床板を支える | 大引 90角＠910、根太 45×45＠303 |
| **母屋・棟木** | 垂木を受ける | 90角＠910 |
| **垂木** | 屋根面を作る | 45×60＠455 |

### スパンから梁せいを決める

木造の梁は **せい = スパン ÷ 10〜12** が目安。

| スパン | 梁せい | 備考 |
|---|---|---|
| 1,820 | 150〜180 | 一般的な間隔 |
| 2,730 | 240 | |
| 3,640 | 300〜330 | **これを超えると集成材か、柱を追加** |
| 4,550 | 390〜450 | 集成材推奨 |

柱間隔 1,820 を基本とし、大きく空けたいところだけ梁を太くする。
**無理に飛ばすより柱を1本立てるほうが安い。** 現実の設計もそうしている。

## RC の部材

| 部材 | 役割 | 断面の目安 |
|---|---|---|
| **基礎（独立/べた/杭）** | 荷重を地盤へ | 地耐力次第。軟弱なら杭 |
| **柱** | 鉛直荷重＋水平力 | 600角前後。スパン 7m で 600〜700 |
| **大梁** | 柱間を結ぶ | **せい = スパン ÷ 10〜12**、幅はせいの 1/2 |
| **小梁** | スラブを分割し支える | せい = スパン ÷ 12〜15 |
| **スラブ** | 床。荷重を梁へ | **厚 = 短辺 ÷ 30〜40**。実用 150〜200 |
| **耐力壁** | 水平力に抵抗 | 厚 180〜200。**抜けない** |
| **開口補強** | 壁の開口周りの応力集中に | 斜め筋・縦横補強筋 |

配筋は主筋（D19〜D25）と帯筋・あばら筋（D10＠100〜200）。かぶり厚は屋外 40、屋内 30。

## 耐震の考え方

- **耐力壁は平面上でバランスよく。** 南面を全部開口にして北面だけ壁、という配置は偏心してねじれる
- 木造は「壁量計算」で必要な耐力壁の長さが決まる。床面積と階数、屋根の重さで変わる
- 上下階で**耐力壁の位置を揃える**。2階の壁が1階の何もない所に乗るのは駄目
- RC 壁式は耐力壁が構造そのものなので、**後から抜けない**

## 開口が構造に効く

- 木造で幅 1,820 を超える開口を取るなら、上の**まぐさ（headers）を梁として設計する**
- 耐力壁に開口は開けられない。開けるなら別の場所で壁量を確保する
- RC 壁式で壁に穴を開けるには開口補強が要り、大きさに上限がある
- **「大きな窓が欲しい」は構造の要求に化ける。** 間取りの希望を聞いたら構造で受けられるか確認する

## ゲームに落とすとき

構造は見えない部分が多いが、**素材と工程と職種を決めるのは構造**である。

- 木造軸組 → 木材（土台・柱・梁・垂木）、金物、筋交い。大工の仕事
- RC → 鉄筋、型枠、生コン。鉄筋工・型枠工・左官の仕事
- S 造 → 鋼材、ボルト、デッキプレート。鳶・溶接の仕事

構造形式を選ばせれば、必要な素材の種類と量、必要な職種、工期が自動的に決まる。
**構造は「リアルにするための飾り」ではなく、ゲームの数値の根拠になる。**
