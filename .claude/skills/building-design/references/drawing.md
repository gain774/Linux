# 作図規約

## 角の納まり — 最初に確認すること

**壁を 2m 単位のブロックとして並べると、直交する壁が交わる格子点で塗りが欠ける。**
これは作図の失敗であって、設計以前の問題。

正しい扱い:

1. 壁は**芯線（centerline）のグラフ**として持つ。区間ではなく連続した線
2. 同一直線上で隣接する区間は**1本の連なりに統合**してから描く
3. 連なりの端部が他の壁と交わるなら、**厚みの半分（t/2）だけ延長**する
4. 開口部は連なりを分割するのではなく、その位置だけ袖・まぐさに置き換える

```
悪い:  [壁][壁]     ← 角に t/2 の欠けができる
       [壁]
       [壁]

良い:  ┌────────    ← 芯線で持ち、交点で t/2 延長
       │
       │
```

## 平面図の慣習

| 要素 | 描き方 |
|---|---|
| 壁 | 断面なので**塗り潰し**（ポシェ）。線ではない |
| ドア | 開口部 + **開き勝手の円弧**。半径 = 扉幅 |
| 引戸 | 開口部 + 戸袋方向に細線 |
| 窓 | 開口内に**細線3本**（外壁線・ガラス・内壁線） |
| 階段 | 段板を平行線で。**上り方向に矢印と「UP」** |
| 寸法線 | 端部は **45度のティック**。矢印ではない |
| 通り芯 | **一点鎖線**。端部に丸囲みで X1, Y1… |
| 切断線 | 一点鎖線を太く。端部に断面記号 A—A |
| 室名 | 室の中央。**面積を併記** |

## ドアの開き勝手

- **室内側に開く**のが原則（廊下に開くと通行の邪魔）
- ただし**便所は外開き**（中で人が倒れたとき開けられるように）
- 壁に沿って開く向きにする。開いた扉が家具や他の扉とぶつからないこと
- 開口幅は有効 750 以上

## 図面一式に含めるもの

- **平面図** — 各階。室名・面積・寸法・通り芯・開口
- **立面図** — 最低でも道路側。開口の位置と軒高
- **断面図** — 階高・天井高・床厚が読めること
- **数量表** — 部品ごとの数量。**設計の制約であって結果ではない**
- **表題欄** — 名称・縮尺・日付・延床・部品数

## gain_build のデータ形式

図面は間取りデータから生成する。データが正であり、図面はその表現。

```python
('h', 0, 0, 'window'),   # (0,0) から東へ 2m、窓つきの壁
('v', 4, 0, 'door'),     # (4,0) から北へ 2m、ドアつきの壁
```

- 第1要素: `h`（水平・東向き）/ `v`（垂直・北向き）
- 第2,3要素: 始点のグリッド座標（メートル）
- 第4要素: `full` / `door` / `window`

部屋は `(名前, x, y, 幅, 高さ)`。すべてメートル。

## 数量の出し方

| 部品 | 数え方 |
|---|---|
| 壁 | 開口の種類ごとに区間数 |
| 床・屋根 | マス数 |
| 柱 | **壁が2方向以上で交わる格子点の数** |

プロップ総数が上限を超えたら、図面を描き直す。48㎡の平屋で約60個が目安。
