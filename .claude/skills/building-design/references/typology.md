# 建築類型

様式を選ぶときの引き出し。相手が「普通の家」としか言わないときは、ここから3つほど提示して選ばせる。
**間取りの型は文化に規定されている。** 「どの国の家か」が決まれば平面の骨格はほぼ決まる。

## 日本

| 類型 | 骨格 | 特徴 |
|---|---|---|
| **田の字型** | 4室を田の字に配置、廊下なし | 農家の基本形。襖で仕切り、開けると大広間になる。**廊下が無いのが正解**の唯一の型 |
| **中廊下型** | 中央に廊下、南に居室、北に水回り | 大正〜昭和の標準。南北で明快に分かれる |
| **nLDK** | LDK + 個室n室 | 戦後の公団住宅から。現代日本の既定 |
| **町家** | 間口が狭く奥に長い。通り庭が貫く | 京都。表店・中庭・奥座敷。細長い敷地への回答 |
| **書院造** | 床の間・違い棚・付書院 | 武家住宅。畳割りが寸法を支配する |

日本の寸法は**910mm（3尺）が基本モジュール**。畳1枚 = 910×1820。柱の芯々が910の倍数。

## 北米

| 類型 | 骨格 | 特徴 |
|---|---|---|
| **Ranch** | 平屋、横に長い、低勾配屋根 | 戦後郊外。ガレージが正面に付く |
| **Colonial** | 2階建て、左右対称、中央玄関 | 玄関ホールから階段が正面に見える |
| **Craftsman bungalow** | 平屋〜1.5階、深い軒、正面ポーチ | 前庭とポーチが社交の場 |
| **Shotgun house** | 部屋が一直線に並び、廊下が無い | 南部。前後の扉を開けると風が通る |
| **Split-level** | 半階ずつずれた床レベル | 傾斜地。ゲームでは階段表現が難しい |

## ヨーロッパ

| 類型 | 骨格 | 特徴 |
|---|---|---|
| **Terraced house（英）** | 側面を隣家と共有、細長い | 前面道路・背面に庭。窓は前後のみ |
| **地中海・中庭型** | 中庭（patio）を囲む | 外に閉じ内に開く。暑い気候への回答 |
| **北欧** | 木造、大開口、薪ストーブ | 冬の日照を最大化。玄関に風除室 |
| **アルプス山小屋（Chalet）** | 急勾配屋根、石造基礎+木造上階 | 積雪。1階が家畜・倉庫だった名残 |

## アジア・中東

| 類型 | 骨格 | 特徴 |
|---|---|---|
| **四合院（中国）** | 中庭を四棟が囲む。南向きの正房が主 | 序列が空間に現れる。北が上座 |
| **韓屋（韓国）** | マダン（庭）+ オンドル床暖房 | 大庁（マル）が夏、온돌部屋が冬 |
| **中東・中庭型** | 中庭 + マシュラビーヤ（格子窓） | 外部に窓を開けない。プライバシーと日射遮蔽 |
| **東南アジア高床式** | 床を上げ、下を風が抜ける | 高温多湿・洪水対策 |

## 非住宅

- **店舗** — 客動線と従業員動線を分ける。バックヤードは客から見えない位置に
- **事務所** — コア（階段・便所・EV）を1箇所に集約し、周囲を執務室に
- **倉庫・工場** — 搬入口 → 保管 → 出荷の一方向。交差させない
- **公共施設** — 不特定多数が入る。動線を単純にし、迷わせない

## 選ぶときの考え方

**気候と文化が平面を決める。** 暑ければ中庭、寒ければ風除室、多湿なら高床。
GTA の舞台は南カリフォルニアなので、Ranch / Bungalow / 地中海系が地の文脈に合う。
ただし RP サーバーは「そこにあり得ない建物」も面白いので、文脈から外すなら意図的に外す。
