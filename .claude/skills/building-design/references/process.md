# 工程と職種

**建物は一度に建たない。** 工程が素材の消費順序を決め、職種が労働力の種類を決める。
gain_build の「素材を運んで労働力を使って建てる」は、この工程をそのままなぞればよい。

## 木造軸組の工程

| # | 工程 | 主な作業 | 素材 | 職種 |
|---|---|---|---|---|
| 1 | 地縄張り・遣り方 | 建物の位置を地面に出す | 杭・貫 | 大工 |
| 2 | 掘方・砕石 | 根切り、転圧 | 砕石 | 土工 |
| 3 | 配筋・型枠 | 基礎の鉄筋を組み型枠を建てる | 鉄筋・型枠 | 鉄筋工・型枠工 |
| 4 | 基礎打設・養生 | 生コン打設。**養生に時間がかかる** | 生コン | 土工 |
| 5 | 土台敷き | アンカーボルトで土台を締める | 土台材・金物 | 大工 |
| 6 | **建方（上棟）** | 柱・梁を組み上げる。1日で一気に | 柱・梁・金物 | 大工・鳶 |
| 7 | 屋根 | 垂木・野地板・防水・葺き | 木材・ルーフィング・屋根材 | 大工・屋根工 |
| 8 | 外壁下地・サッシ | 面材、防水シート、窓 | 構造用合板・サッシ | 大工 |
| 9 | 断熱・防水 | 充填、気密 | 断熱材 | 大工 |
| 10 | 設備 | 給排水・電気の配管配線 | 配管・電線 | 配管工・電工 |
| 11 | 内部造作 | 床・壁・天井の下地と仕上げ | 石膏ボード・床材 | 大工・内装 |
| 12 | 仕上げ・外構 | 塗装、建具、外構 | 塗料・建具 | 塗装・左官 |

**要点**: 4 の養生は待ち時間であって労働力を消費しない。
6 の建方は短時間に多人数が要る。**工程ごとに必要な人数と日数が違う**のが現実で、
ゲームの「その日の労働力」を面白くするのはこの偏りである。

## RC の工程

木造と大きく違うのは、**打設と養生が繰り返される**こと。

1. 山留め・掘削 → 2. 捨てコン → 3. 基礎配筋・型枠・打設 → **養生**
→ 4. 柱・壁の配筋 → 5. 型枠建込み → 6. 打設 → **養生** → 7. 型枠解体
→ 8. 梁・スラブの配筋・型枠 → 9. 打設 → **養生** → （階を繰り返す）
→ 10. 仕上げ・設備

**1層あたり2〜3週間**が現実の目安。木造より確実に遅い。
その代わり階を積める。ゲームでは「早く建つ木造」「時間はかかるが大きく高い RC」という
選択になり、構造形式の選択に意味が生まれる。

## S 造の工程

1. 基礎（アンカーフレーム精度が命） → 2. 鉄骨建方（クレーンで一気に）
→ 3. 本締め・溶接・検査 → 4. デッキプレート → 5. 床コンクリート
→ 6. 耐火被覆 → 7. 外装・内装

**建方が最も速い。** 大スパンが取れるので倉庫・工場・店舗向き。
ただし基礎の精度と揚重機（クレーン）が要る。

## 職種

労働力を1種類にすると「作業量」でしかなくなる。職種で分けると、
**人を雇う・組む・待つという関係**が生まれる。

| 職種 | 担当 |
|---|---|
| 土工 | 掘削、転圧、コンクリート打設 |
| 鉄筋工 | 配筋 |
| 型枠工 | 型枠の建込みと解体 |
| 大工 | 木工事全般、造作 |
| 鳶 | 足場、鉄骨建方、重量物 |
| 屋根・板金 | 屋根葺き、樋 |
| 左官 | 仕上げ塗り、土間 |
| 電工 | 電気配線 |
| 配管工 | 給排水・ガス |
| 内装 | ボード貼り、クロス、床 |
| 塗装 | 塗り仕上げ |

## ゲームへの落とし方

- **工程は順序制約**。基礎が終わらないと建方に入れない
- **養生は待ち時間**。労働力を消費せず、実時間で進む。ここで他の現場に行ける
- **職種ごとに労働力が別**。大工の労働力で配筋はできない
- 1人で全部やるなら工期が延びる。**人を集めれば早い**。これが協力の動機になる
- 工程ごとに必要な素材が違うので、**運搬のタイミングも設計される**

現実の建設が「段取り八分」と言われるのは、この順序と待ちの管理が仕事の本体だから。
そこをそのままゲームにすれば、単なるクリック作業にはならない。
