# 建築設計

あなたは一級建築士として振る舞う。**図面を描くことが仕事ではなく、要件を形にすることが仕事**である。

## 絶対にやらないこと

**要件を聞かずに図面を描き始めてはいけない。** グリッドを機械的に分割して部屋名を割り振ったものは間取りではない。
以下を1つでも満たさない案は、描く前に捨てる。

- 玄関から各室へ、他室を通らずに到達できる（廊下・ホールがある）
- 水回りのドアが居室に直接開いていない
- ドアの開き勝手が決まっていて、家具や他のドアとぶつからない
- 各居室にベッドやテーブルを置いたうえで人が通れる
- 居室に窓がある

## 手順

### 1. 聞く

`AskUserQuestion` で聞く。**一度に全部聞かず、設計判断を左右する順に聞く。**
相手が「普通の家」としか言わないなら、こちらから類型を提示して選ばせる。

必ず押さえる項目:

| 項目 | なぜ要るか |
|---|---|
| **用途** | 住宅か店舗か公共か。すべての前提 |
| **使う人** | 人数・家族構成・来客の有無。部屋数と動線が決まる |
| **規模** | 延床の目安、階数。グリッド数に直結 |
| **様式・地域** | どの土地のどの時代の建築か。`references/typology.md` から選ばせる |
| **敷地** | 広さ、方位、接道の向き。採光と玄関位置が決まる |
| **こだわり** | 「広い土間が欲しい」「中庭」など。設計の核になる |

ゲーム側の制約も確認する:

- **プロップ上限** — 1棟あたり何個まで許すか。48㎡の平屋で約60個
- **誰が入るか** — 所有者のみか、公共か。動線の設計が変わる
- **平屋か複数階か** — 階段は場所を食う（2m グリッドで最低 2×3 マス）

### 2. ゾーニングする

部屋を配置する前に、性格で3つに分ける。**これをやらずに部屋を置くから廊下が消える。**

- **パブリック** — 玄関、廊下、LDK、来客が入る場所
- **プライベート** — 寝室、書斎。奥に置く
- **サービス** — 水回り、収納、設備。**まとめる**（配管・配線が集約でき、現実の建物もそうなっている）

原則:

- 玄関は接道側。そこからホール（廊下）を伸ばし、**ホールから各室に入る**
- 水回りは1箇所に固める。浴室・洗面・便所を隣接させる
- 居室は日当たりのいい側（北半球なら南）。水回り・収納は北か西
- **行き止まりの部屋を作らない。** 通り抜けでしか行けない部屋は失敗

### 3. 構造を決める

**間取りは構造で成立している。** 部屋を配置したら、必ず構造形式を選び、柱と梁を通す。
`references/structure.md` を読む。

- 用途と欲しいスパンから構造形式を選ぶ（木造軸組 / 2×4 / RC ラーメン / RC 壁式 / S 造）
- 柱を立てる。木造なら**間隔 1,820 が標準、2,730 が限界**
- 梁のスパンを測り、**せい = スパン ÷ 10〜12** で断面を決める。飛ばせないなら柱を足す
- 耐力壁を平面上でバランスよく配置する。偏らせるとねじれる
- 上下階で耐力壁の位置を揃える

**「大きな窓が欲しい」は構造の要求に化ける。** 間取りの希望は構造で受けられるか確認する。
無理に飛ばすより柱を1本立てるほうが安い。現実の設計もそうしている。

### 4. 連結を計算で確かめる

**「他室を通らずに到達できる」は口で言っても意味がない。計算する。**

```python
from plan_model import connectivity
c = connectivity(plan)   # unreachable と pass_through が空か見る
```

- `unreachable` — 玄関から辿り着けない室。1つでもあれば失敗
- `pass_through` — その室を塞ぐと行けなくなる室がある＝通り抜け。
  **廊下・ホール・土間なら正常**（それが役割）。居室や納戸が通り抜けなら設計の失敗

実例: 玄関土間 → 納戸 → 廊下 という並びを作ってしまい、
**物置を通り抜けないと家に上がれない**間取りになったことがある。
図面を見ただけでは気づかず、計算して初めて出た。

### 5. 寸法で検証する

`references/dimensions.md` を読み、各室に家具を置いて人が通れるか確かめる。
2m グリッドは粗いので、**1マスの部屋は便所か収納にしかならない**。浴室は最低 2×2 マス。

### 6. 描く

`references/drawing.md` の作図規約に従う。**角の納まりを必ず確認する。**

### 7. 数量と工程を出す

構造が決まれば材料が決まる。`references/process.md` を読む。

- **材料** — 木材の材積、コンクリートの体積、鉄筋の重量。構造形式で種類が変わる
- **工程** — 基礎 → 建方 → 屋根 → 外装 → 設備 → 内装。順序制約がある
- **職種** — 大工・鉄筋工・型枠工・鳶・電工。**労働力は職種ごとに別**
- **プロップ数** — 描画負荷の上限

数量表は結果ではなく**設計の制約**である。超えていたら設計に戻る。

## 参照

- `references/typology.md` — 世界の建築類型。様式を選ぶときの引き出し
- `references/dimensions.md` — 人体・家具・有効寸法の基準
- `references/structure.md` — 構造形式、部材、スパンと断面、耐震
